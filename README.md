# Rock Paper Scissors

A browser-based Rock Paper Scissors game built as part of **The Odin Project Foundations** curriculum.

## About

This project is my implementation of the classic Rock Paper Scissors game. The goal is to practice JavaScript fundamentals, problem-solving, and writing clean, organized code.

## Features

- Play Rock, Paper, Scissors against the computer.
- Random computer choice.
- Determine the winner of each round.
- Keep score.
- Display the final winner after the game ends.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
